# Marketing Master Class: SEO & SEM

If a business relies entirely on Paid Ads, it is fragile. SEO builds a moat of free, high-intent traffic that pays dividends for years.

## ✅ ALWAYS

1.  **Understand Search Intent**:
    -   *Informational*: The user wants to learn (e.g., "how to fix a leaky pipe"). Write long-form, educational blog posts.
    -   *Transactional*: The user wants to buy (e.g., "plumber near me 24/7"). Send them to a high-converting Landing Page, NOT a blog post.

2.  **Technical SEO (The Foundation)**:
    -   Page load speed is a ranking factor (Core Web Vitals). Ensure images are compressed (`WebP`/`AVIF`) and JavaScript is deferred.
    -   URL structures MUST be clean: `acme.com/services/plumbing`, NEVER `acme.com/p=123?service=plumb`.

3.  **Semantic HTML & Hierarchy**:
    -   A page MUST have exactly one `<h1>` tag containing the primary keyword.
    -   Use `<h2>` and `<h3>` tags to structure content logically. Search engine crawlers read this hierarchy to understand the context.

## ❌ NEVER

-   **Keyword Stuffing**: Do not write "We are the best plumbers in London, if you need London plumbing call our London plumbers." Write for humans first, bots second.
-   **Ignore Meta Tags**: Every page MUST have a compelling `<title>` (under 60 chars) and `<meta name="description">` (under 160 chars) designed to maximize CTR in the Google Search Results.
